# 🎯 Hand Tracking Fruit Shooter (Python Tkinter + OpenCV)

An interactive 2D arcade-style shooting game built with **Python**, **Tkinter**, **OpenCV**, and **MediaPipe**. Players use real-time webcam hand tracking to control an aim reticle with their index finger and pinch their thumb and index finger together to shoot falling targets within a 60-second timer.

---

## 🌟 Key Features

* 🖐️ **Webcam Hand Tracking:** Real-time reticle control using MediaPipe computer vision.
* 👌 **Pinch-to-Shoot Mechanics:** Pinch your index finger and thumb together to fire.
* 🎯 **Dynamic Target Scoring:**
  * 🟢 **Green Target (Large):** 10 Points
  * 🟡 **Yellow Target (Medium):** 20 Points
  * 🔴 **Red Target (Small):** 30 Points
* ⏳ **Game Engine & UI:** Built with Tkinter featuring a 3-second countdown, 60-second timer, real-time score display, and animated targets.
* 🏆 **Top 5 Leaderboard & Match History:** Tracks guest player names, top 5 high scores, and expandable recent match logs.
